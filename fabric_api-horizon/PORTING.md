# Fabric API on Horizon

A Horizon native-mod bundle generated by horizon-port from `fabric-api-0.165.2-26.3.jar`. It builds as it is and plays like vanilla: every injection that is on leaves the game unchanged until its `TODO` is filled in. 1 injections are on; 0 are written commented out in `mixins/fabric_api/horizon-mixin.toml`, with why.

## What each part became

| Java | State | What to do |
| --- | --- | --- |
| hook `mods` | on | The mod's row in Options > Mods. |
| Java logic (classes that don't need the game) | translated 0 of 0 methods | In runtime.rs, `pub mod java`. Each method is translated whole or left out with why: report/translation.md. |

## Build it

Horizon's launcher builds a bundle folder itself (it downloads its own Rust the first time):

```bash
horizon-launcher native-build "<this folder>" --trust-native-code
```

Native mods run with your rights and aren't sandboxed: build only code you have read. `cargo test` here runs `runtime.rs`'s own tests without the game.

## Limits

- The mod's own logic that doesn't need the game is translated into `runtime.rs` (`pub mod java`): Translated 0 of 0 methods and 0 of 0 static fields to Rust. Code that uses Minecraft classes isn't: each helper lists the game calls its Java makes and what they are in Horizon. See `report/translation.md`.
- `BEFORE_CALL`, `AFTER_CALL`, `MODIFY_ARG` and `WRAP_OPERATION` select the called function by name (`selector`), with `require` counted in the target's source. horizon-mixins checks both when it plans: a mismatch fails the build with a message, it never applies silently.
- Raw targets are functions of one Horizon commit (`a46ce6898bd72016e061aaec1afc1375b384deac`): a newer Nightly may move them.

## Ready to use?

**Yes: this is a full port.** `fabric_api.hnmod` is Horizon's file for a native mod. To play it:

1. Put it in `horizon-native-mods/` in Horizon's game folder (`%APPDATA%\horizon` on Windows, `~/.local/share/horizon` on Linux) and add the line `mod.fabric_api:true` to `horizon-mods.txt` there (the app's "Add it to Horizon" does both).
2. In Horizon's launcher, turn on Settings > Game > Native mods and press **Build** on the Mods page, or run
   `horizon-launcher native-build --trust-native-code`. The launcher compiles it into the game (the first build downloads Rust and takes 10 to 30 minutes).

Native mods run with your rights and aren't sandboxed: build only code you trust.
