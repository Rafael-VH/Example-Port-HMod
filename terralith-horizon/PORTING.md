# Terralith on Horizon

A Horizon native-mod bundle generated by horizon-port from `Terralith_26.3_v2.6.5+26.3.jar`. It builds as it is and plays like vanilla: every injection that is on leaves the game unchanged until its `TODO` is filled in. 4 injections are on; 0 are written commented out in `mixins/terralith/horizon-mixin.toml`, with why.

## What each part became

| Java | State | What to do |
|---|---|---|
| hook `mods` | on | The mod's row in Options > Mods. |
| hook `tick` | on | The mod's initializer, run once on the first tick |
| hook `settings` | on | The mod's settings page (it has a config screen). |
| hook `settings_click` | on | Clicks on that page. |
| Java logic (classes that don't need the game) | translated 5 of 39 methods | In runtime.rs, `pub mod java`. Each method is translated whole or left out with why: report/translation.md. |
| Fabric initializer at net/stardustlabs/terralith/TerralithFabric.java:9 | not translated | Not translated: it calls ConfigHandler.load, which isn't translated. |

## Build it

Horizon's launcher builds a bundle folder itself (it downloads its own Rust the first time):

```bash
horizon-launcher native-build "<this folder>" --trust-native-code
```

Native mods run with your rights and aren't sandboxed: build only code you have read. `cargo test` here runs `runtime.rs`'s own tests without the game.

## Limits

- The mod's own logic that doesn't need the game is translated into `runtime.rs` (`pub mod java`): Translated 5 of 39 methods (1 more is done another way in Horizon) and 4 of 11 static fields to Rust; 0 of 1 Fabric event handlers. Code that uses Minecraft classes isn't: each helper lists the game calls its Java makes and what they are in Horizon. See `report/translation.md`.
- `BEFORE_CALL`, `AFTER_CALL`, `MODIFY_ARG` and `WRAP_OPERATION` select the called function by name (`selector`), with `require` counted in the target's source. horizon-mixins checks both when it plans: a mismatch fails the build with a message, it never applies silently.
- Raw targets are functions of one Horizon commit (`a46ce6898bd72016e061aaec1afc1375b384deac`): a newer Nightly may move them.

## Ready to use?

**No: this isn't a full port**, so no `.hnmod` was made. What's left:

- 7 static fields aren't translated (see `report/translation.md`).
- Fabric initializer at net/stardustlabs/terralith/TerralithFabric.java:9: not translated.
- 2 TODOs are left in the code:
